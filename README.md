# rock-paper-scissors

The third project in the Foundations course of The Odin Project - after the lesson "Revisiting Rock Paper Scissors".

Now, the assignment only asks to add a couple buttons and a div for displaying the result. While that was a nice task, I felt like I can't apply my favourite motto:

"If life is too easy, overcomplicate it!"

So, since I have a little experience in Godot, I naturally thought I would make it into a bit more interactive game. I still wanted to keep it relatively simple though, and this is what I settled on. The controls are easy: WASD to move, Space to restart after the game is over. What more could I need? (Well, there's another modification: every third consecutive hit is a crit, and does double damage.)

However, I still wanted to include my original assignment too (what the lesson actually asked for). So I included both; you can access either from the index page.
